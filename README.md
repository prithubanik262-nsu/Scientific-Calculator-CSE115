# Scientific-Calculator-CSE115
This is the 1st semester project of a scientific calculator for CSE115

# Features

1. Arithmatic Operations (including imaginary numbers)
2. Logarithmic Operations\
3. Power_Root (also handles imaginary numbers' cases)\
3. Trigonometry Operations( sin(), arcsin() etc.)\
4. Matrix(addition, subtraction, multiplication, inverse, diterminant)\
5. Vector(dot and cross)\
6. Factorial and Permutation\
7. Conversion( temp, distance, speed)\
8. Polynomial roots solving(including imaginary numbers)\
